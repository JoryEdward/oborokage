# 胧影剑录 · Oborokage 0.3.0

Minecraft **1.26+ (26.x+)** / Fabric Loader **0.16.10+** / Fabric API / Java **25**。
五把原创刀、双刀连招、架刀反击、第三人称奥义、可控斩物及十四项成就。

## 五把刀

| 名称 / ID | 用途 | 右键满蓄力 |
|---|---|---|
| 胧影太刀 `oborokage:tachi` | 长距离直线居合、强敌终结 | 40 tick；1000 点输入及原有终结流程 |
| 胧月脇差 `oborokage:wakizashi` | 副手连招、架刀、反切 | 放在副手，与任一主刀配合 |
| 赤霆刀 `oborokage:raikiri` | 快速近距离追击 | 20 tick；直线突击，基础技能伤害最高112 |
| 霜轮太刀 `oborokage:frostmoon` | 被包围时范围控制 | 40 tick；最大6格范围霜斩与减速，基础技能伤害最高88 |
| 空弦太刀 `oborokage:voidstring` | 远距离精准剑气 | 40 tick；最远28格、受实心墙阻挡，基础技能伤害最高144 |

新刀的技能会计算力量、虚弱、攻击属性及所用刀的附魔，表中数值是默认基础值。原胧影的蓄力伤害、4096耐久、突进时序、18/45 tick冷却及2/8点战斗耐久消耗保留。

在独立 **“胧影”创造栏** 获取，也支持创造搜索和 `/give @s oborokage:tachi`；替换最后的ID可获取其他刀。五把刀均有主世界工作台配方和原版配方书解锁。

## 操作

- **右键按住、松开**：当前主刀技能。至少4 tick才有效。胧影满蓄力仍为约2秒。
- **主刀 + 副手脇差，左键**：主手 → 副手 → 双手交叉斩。末段命中后可破势；短输入缓冲允许提前衔接。
- **H按住**：交叉架刀。起手默认4 tick为精准窗，服务端按半个RTT补偿，最多增加3 tick。精准架刀能弹回正面箭矢，随后左键反切。
- **V**：影步。没有方向输入时后退，按方向键时按输入移动；实心墙会限制移动。
- **J**：100剑意释放双月奥义。范围多段破势后终斩，终斩保留1000输入及终结。自己的镜头可临时切为第三人称，结束后恢复。
- **下蹲 + 主手右键蓄力、松开**：斩物。所有主刀的斩物满蓄力均为40 tick。

H/V/J可在控制设置重绑定。首次装备双刀会显示招式说明，并检查实际键位冲突；遇到冲突会指出另一绑定的名称。

本地先播放自己的动作，服务器确认后对齐；伤害、命中、资源消耗和破坏均由服务器决定。服务器拒绝的动作会取消呈现。

## 斩木与斩物

瞄准树干后下蹲蓄力出刀，会沿相连原木向上查找。默认短蓄力斩少量木头，满蓄力最多32格，每tick最多4格；不会自动伐叶或无限扩散到森林。其他方块按命中面的有限切面处理，蓄力越高，数量与硬度上限越高。

默认硬度上限5，跳过箱子等方块实体、不可破坏方块、流体、未加载区块和世界边界外目标。每一格都走原版玩家破坏与Fabric破坏事件，保护插件拒绝时停止本次斩物，冒险模式仍受限制。创造模式只在这次显式斩物流程允许刀破坏方块。

生存原木会按原版掉落。石头、矿物仍遵守原版“正确工具”掉落规则；刀不会变成镐。战斗蓄力不会自动破坏地形。除技能耐久外，斩物也会产生原版逐方块采掘耐久消耗。

## 配置

`config/oborokage-server.properties`：修改后运行原版 `/reload`。
`config/oborokage-client.properties`：修改后重新启动客户端。
完整字段和边界见 [配置说明](docs/CONFIGURATION.md) 及 `config-examples/`。

默认模组技能不伤玩家，并保护自己的宠物、盟友、村民和铁傀儡；服务器可分别调整。对敌人的原胧影强度保留。
第三方特殊不死实体可加入实体类型标签 `oborokage:finisher_exempt`，该标签默认空：免除强制终结，仍承受普通伤害。非豁免目标会经过原有死亡流程及一次有界重试，仍存活则限频记录日志；第三方代码若主动阻止死亡或重写生命值，无法承诺通用兼容。

支持原版武器附魔。新招式调用实际所用刀的伤害、击后效果与击退；横扫之刃在交叉斩、范围招式上给予额外伤害。原刀的终结强度独立保留。

## 成就

原十项剑录保留。新增“一息，林木应声”（一次斩16原木）、“霜轮止戈”（一次减速3敌人）、“隔岸一线”（剑气命中16格外敌人）、“五刃同途”（同时携带五刀）。聊天公告默认关闭，可在服务端开启；个人提示与进度页仍可见。

## 安装与回退

将一个 `oborokage-tachi-0.3.0.jar` 放进目标Fabric实例的 `mods/`，移出旧版同Mod ID JAR。多人客户端和服务器应使用同版本。

**升级后有新增刀的世界不能直接降回0.1.0。** 实测旧版加载并保存后，脇差和新刀会消失，重新升级也不恢复。需要回退时，应同时恢复升级前的模组、配置和世界备份。本次安装备份路径及哈希在 [验证与交付](VERIFICATION.md) 中。
