# 胧影 · Oborokage 0.2.0

Minecraft 26.3 / Fabric Loader 0.19.5+ / Fabric API 0.162.0+26.3 / Java 25。
独立 Mod ID `oborokage`，产物 `oborokage-tachi-0.2.0.jar`。

## 原版太刀强度

保留 `oborokage:tachi` 和旧物品数据。原居合执行器为 `LegacyIaido`：

- 最低有效释放 4 tick、40 tick（约 2 秒）满蓄力。
- 伤害 `15 + 985 × 蓄力比例²`；满蓄力输入 1000，存活目标沿用旧终结处理。
- 满蓄力前摇 12 tick，6 tick 突进，每 tick 请求移动 `0.9 + 1.1 × 蓄力比例` 格；无障碍满蓄力约 12 格，墙体阻挡。
- 部分/满蓄力冷却 18/45 tick，消耗 2/8 耐久，总耐久 4096。
- 原近战注册属性、稀有度和耐火属性保留。剑意、架势、成就和双刀奥义冷却不限制原居合。

原刀右键居合可打断新增动作。旧终结的第三方不死脚本兼容边界仍存在；已验证原版 Boss 与高血量防护组合，不保证所有外部模组都遵循正常死亡处理。

## 两把刀与独立分类

创造模式新增 **胧影 / Oborokage** 分类，第一排依次为胧影太刀、胧月脇差；从原版战斗栏移到此分类。创造搜索继续包含两把刀。标签页较多时，使用创造栏内部右上角的小箭头翻到胧影页。

```mcfunction
/give @s oborokage:tachi
/give @s oborokage:wakizashi
```

主手太刀、副手脇差形成双刀流。脇差有独立模型、图标和 2048 耐久，单独放主手时可当普通近战武器使用。长刀与短刀分别扣耐久、保存附魔和掉落，不合成为隐藏“成套物品”。两刀加入本机原版 swords 标签，支持相应原版武器/耐久附魔；新招式读取对应武器的伤害附魔。

## 操作

| 操作 | 效果 |
|---|---|
| 右键按住/松开 | 原版太刀居合；单刀与双刀时都保留 |
| 双刀左键 | 主手斜斩 → 副手反切 → 交叉双斩，可提前输入下一段 |
| H 按住 | 交叉架刀，起始约 0.2 秒为精准格挡窗 |
| 精准架刀后立即左键 | 对来袭者施放「错月反切」 |
| V +移动方向 | 约 2.8 格影步；无方向输入时后撤，结束可接副手快斩 |
| J（剑意 100 时） | 双刀奥义「双月·归寂」 |

H/V/J 可在控制设置的“胧影 · 双刀”里重绑定。本机 G 与快捷操作、R 与其他模组已有绑定，因此使用 H/J 代替。挖掘方块和正常容器交互保留，双刀自定义左键攻击不与原版实体攻击重复结算。

精准格挡取消允许类型的前方普通近战伤害，打开短暂反切窗口并增加剑意；持续架刀减伤 65%，消耗架势，架势不足会破防。背后、环境、爆炸和魔法伤害不被当作普通近战拦截。格挡窗和伤害均由服务器判断。

有效命中增加剑意，精准格挡增加更多；实际受伤消耗剑意，长时间脱战后缓慢衰减。空挥、零伤害和短间隔刷同一目标不会无限增益。剑意只用于新增双刀奥义；奥义发动即消耗，取消不返还。

对敌人的连续有效命中积累本模组破势状态，破势窗口内伤害提高；普通低生命怪可短暂迟缓，高生命实体只开放伤害窗口，未清空 Boss AI。影步与奥义突进使用服务器碰撞，不瞬移穿墙，也不免疫摔伤。

## 奥义与美术

「双月·归寂」依次为交叉蓄势、主副手分次出刀、转体交叉终斩、两刀收势。终斩沿实际范围使用同等级 1000 输入与终结策略。银紫/青白的两股世界空间刀光、两侧刀鞘、独立左右手动作和本地环绕镜头共同演出。

第一人称与左右利手分别处理。奥义镜头只控制施术者，旁观者看到角色动作和刀光。旧奥义「胧月一闪」继续可用。

[空][铁块][钻石]        [空][紫水晶碎片][铁锭]

获得紫水晶碎片后，两张配方自动进入配方书；已在临时世界验证服务端解锁与客户端显示。输出完整耐久的同一注册物品。无需下界/末地材料或额外工作台；不消耗已有太刀来制作双刀套装。

## 胧影剑录：10 项进度

独立进度页中共有以下 10 项：

| 名称 | 达成方法 |
|---|---|
| 初见胧月 | 获得任意一把胧影武器；老玩家已有刀或旧挑战完成也会补足 |
| 双月同鞘 | 主手太刀、副手脇差连续装备 20 tick |
| 双月同辉 | 同一三连中两手均有效命中，交叉末段击败敌对生物 |
| 借你一刀，还你一月 | 精准架刀后，在 12 tick 反击窗发动反切并击败此次攻击者 |
| 一步千钧 | 影步实际移动至少 2 格且未被墙截停，随后 12 tick 内副手有效命中敌对生物 |
| 三息不乱 | 20 秒内精准格挡 3 次独立近战攻击，全程未实际受伤 |
| 破势见锋 | 将目标打入破势状态，在该窗口用交叉斩有效命中 |
| 双月归寂 | 双刀奥义最终一击击败敌对生物 |
| 长夜无伤 | 60 秒内双刀击败 5 个不同敌对生物，至少 3 次不同动作，两手均在当前窗口内有效命中，未实际受伤 |
| 刀已归鞘，月仍未落 | 原挑战：一次满蓄力居合击败至少 3 个非玩家生物，至收势未受伤 |

旧成就保留 ID/条件，仅迁移父节点；已有完成状态保留。根节点依据真正获得武器或旧挑战已完成自动补足。所有招式无需先完成成就；进度不额外增加装备。

## 配置与兼容

`config/oborokage-server.properties`：`allowPlayerDamage=false`。默认保护使用者和其他玩家；开启玩家伤害后仍保留创造/旁观和队伍保护。

`config/oborokage-client.properties`：

```properties
cinematic=true
thirdPersonUltimate=true
screenShake=true
```

修改后重启；可分别关闭电影表现、自动第三人称和震动。攻击判断、剑意与成就仍由服务器处理。数据包可向 `oborokage:hostiles` 实体类型标签加入未实现 Enemy 接口的敌对模组生物，以支持新成就与剑意统计。

## 构建、验证与回退

Java 25 下执行 `./gradlew --offline build`。发布 JAR 和源码 JAR 位于 `build/libs/`。

`verification/run.py server` 为隔离服务端规则检查，`verification/run.py client --fullpack` 为复制整合包的临时世界实机检查，`verification/network.py` 为本机独立专用服务器加两个独立客户端的联机检查，`verification/recipebook.py` 只检查原生库存事件触发的配方书解锁。测试程序未打入发布 JAR。

结果、截图、安装哈希和未验证事项见 `VERIFICATION.md`。

回退：退出游戏，移除 0.2.0 JAR，将 `backups/release-20261016/oborokage-tachi-0.1.0.jar` 复制回正式 mods。同一 Mod ID 只启用一份；更新前配置也在该目录。最初的源码备份在 `backups/expansion-20261015/source-0.1.0.tar.gz`。回退不需要操作世界存档，但旧版不会识别新增脇差，因此有脇差的世界回退前应先另存备份。

本轮代码、短刀模型、图标、背景与动作/刀光均为项目自写；声音使用 Minecraft 原版资源，没有参考音视频下载文件。原水桶弓保持冻结。

## 后续与限制

流派专精树、空中派生、任意剑混搭和两把长太刀组合尚未加入。本版只支持主手太刀 + 副手脇差的双刀组合。具体光影包、远程高延迟网络、所有第三方战斗/相机模组，以及全部异常/动作组合仍需各自实测；本地双客户端通过不代表这些都已通过。
