# 胧影剑录 · Oborokage 0.6.2

支持 Minecraft **26.x 全部正式版**（26.1 / 26.1.1 / 26.1.2 / 26.2 / 26.3），Java **25**。
五把原创刀各有专属外观、粒子、刀光与奥义动画；单持任一把刀有自己的三段连斩，双持有双刀连招，另有四刀流派终式、见切与影返、架刀反击（含远程）、可控斩物及十八项成就。

## 选择对应版本的 JAR

| 你的 Minecraft | 放入 mods 的文件 | Fabric Loader | Fabric API |
|---|---|---|---|
| 26.1、26.1.1、26.1.2 | `oborokage-tachi-0.6.2+26.1.jar` | ≥0.18.4 | ≥0.145.1 |
| 26.2 | `oborokage-tachi-0.6.2+26.2.jar` | ≥0.18.4 | ≥0.161.0 |
| 26.3 | `oborokage-tachi-0.6.2+26.3.jar` | ≥0.19.3 | ≥0.162.0 |

三个文件玩法、数值、存档数据完全相同，只是分别针对各版本线的游戏接口编译。每个 JAR 都写明了适用版本范围，放错版本时 Fabric 会在启动时直接提示，不会进入游戏后才出错。

## 操作

- 骑乘、鞘翅滑翔或旁观模式下，左键仍是原版攻击 / 旁观操作（0.6.2）。
- **单持任一把刀，左键**：三段连斩——袈裟斩 → 逆袈裟 → 踏步横斩；第三段带出这把刀的终式（见下表）。命中会积累剑意、施压破势，伤害高于原版普攻。
- **右键按住、松开**：当前主刀技能。至少4 tick才有效。胧影满蓄力仍为约2秒。蓄力分四段推进，每一段脚下光阵加一层、响一声、计量条亮一格；满蓄力时出现这把刀的征象。
- **主刀 + 副手脇差，左键**：主手 → 副手 → 双手交叉斩。末段命中后可破势；短输入缓冲允许提前衔接。
- **H按住**：交叉架刀。起手默认4 tick为精准窗，服务端按半个RTT补偿，最多增加3 tick。精准架刀能弹回正面箭矢，随后左键反切。
- **V**：影步。没有方向输入时后退，按方向键时按输入移动；实心墙会限制移动。
- **J**：剑意满 100 时释放**手中这把刀**的奥义，不再要求双刀。奥义期间生物与投射物的攻击无法打断；结束后获得 5 秒“残心”（速度 I）。自己的镜头会按各刀的运镜切为第三人称，结束后恢复；其他玩家看得到全部世界特效。
- **剑意**：单刀与双刀连斩命中、精准架刀、见切、本刀技命中（每敌 +6）、居合命中（+10）都会积累；满 100 后不再流失，可以等待时机。
- **下蹲 + 主手右键蓄力、松开**：斩物。所有主刀的斩物满蓄力均为40 tick。

持刀瞄准方块时，只有附近敌对生物会让首次左键优先出刀；牛、村民等不会抢走挖掘点击，下蹲始终保留原版挖掘路径。继续按住左键仍由原版处理挖掘。

H/V/J可在控制设置重绑定。首次装备双刀会显示招式说明，并检查实际键位冲突；遇到冲突会指出另一绑定的名称。

本地先播放自己的动作，服务器确认后对齐；伤害、命中、资源消耗和破坏均由服务器决定。服务器拒绝的动作会取消呈现。按住架刀被拒绝后，本次持续按住不再反复预测；heartbeat仍会在服务端条件满足后启动真实架刀。

## 0.6.0 新玩法与演出

- **单刀三段连斩**（每段基础 16 / 18 / 28，四把新刀再 ×1.3；末段带横扫附魔加成与轻微击退）。末段终式：

  | 刀 | 终式 | 效果 |
  |---|---|---|
  | 胧影 | 残月 | 0.3 秒后刀影对被斩中的敌人再斩一次（45%） |
  | 胧月脇差 | 落花 | 末段回身一周（360°），命中后获得 2 秒速度 I |
  | 赤霆 | 雷闪 | 雷光从每个被斩中的敌人跳向附近敌人（40%，最多 4 道），可打到刀够不着的敌人 |
  | 霜轮 | 霜华 | 每斩叠霜，三层冻结；末段令被斩者减速并震出一圈冰环 |
  | 空弦 | 虚刃 | 剑气沿斩线再走 7 格，打到后排（50%） |

  所有刀的普攻（单刀三段、双刀三连、反切）都沿**视线**出刀，并在落刀那一刻重新取视线（0.6.2）：起手后转动视角，刀会斩向新的方向；抬头可斩到头顶的敌人，低头可斩到脚下的敌人；虚刃剑气也沿视线射出。刀光与手臂随视线俯仰。奥义仍按施展时的朝向演出。

- **每把刀的刀光**：不再是两条彩色光弧。每一刀都是带刀面光幕、高光刃线、残影和刃尖闪光的斩痕——胧影是厚重的月色新月拖着两道朦胧残影；胧月是又细又快、洒下花瓣的珠光；赤霆是每一 tick 都重新劈出的锯齿雷刃和飞散的支电；霜轮在斩过之处留下一排慢慢融化的冰棱；空弦是暗色光晕中的一根细弦，斩完后还会颤动片刻。连段末一击更大更亮，并在地面荡开光环。命中点有按刀上色的闪光。
- **打击感**：自己的刀砍中东西时画面顿一下（顿帧，逻辑节奏不受影响）、镜头轻震；末段命中时屏幕边缘按刀色一闪。第一人称下刀光改画成横过视野的新月。
- **蓄力的层次**：四段推进——转动的虚线环 → 反向的刻度环 → 宽环上的四道新月 → 脚边升起光柱；满蓄力时胧影背后升起新月、赤霆雷电沿光阵攀上刀柄、霜轮冰棱成冠并在地面画出霜纹、空弦细弦从四周拉向头顶。蓄力时身体随之沉腰，画面边缘按刀色渐暗，计量条分成四格。
- **本刀技特效**：赤霆突击沿路留下雷电、支电与焦痕；霜轮霜环在地面画出霜纹，冰棱沿环破土而出；空弦剑气是暗色光晕中的光弦，松开后颤动，末端撕开一道裂隙。雷链、虚刃、回霜、残月也都有各自的光效。
- **胧月一闪重做**（满蓄力居合，施展方式不变）：蓄势时巨大的淡月从身后升起、脚下水纹般的光环；拔刀后以约 15 格的强烈突进贯穿敌阵，斩线化作刺目的光痕与风压线；途经的敌人只是被“标记”，原地定住、身上留着一道细细的刀痕；你静立不动，画面沉入寂静，镜头绕到你的正面，身后定格着敌人；振刀、收刀入鞘的“咔”一声——月亮沿刀痕裂开，悬在空中的光痕爆散，所有被斩的敌人在同一刻倒下，花瓣沿整条斩线飘落。
- **奥义名更醒目**：五个奥义的名字在施展后很快写出，整段奥义期间保持，关键一击时再亮一次，并在镜头交还后继续停留约 3 秒再淡出。
- **奥义伤害上调**（胧月一闪除外）：双月归寂前两斩 65 → 85、胧月百花缭乱每斩 16 → 22、万雷天降 70 → 90、镜月冰河 72 → 95、断界 150 → 190。

## 0.4.0 新玩法

- **见切 · 影返**：影步起手的前 3 tick 内，来自生物或投射物的攻击会被完全避开，获得 10 剑意（每秒最多一次）。随后 20 tick 内落下的下一刀伤害 ×1.5，HUD 显示“影返”。
- **流派终式**：双刀三连的最后一记交叉斩，按主手刀带出不同效果。
  - 胧影 · 月蚀：交叉斩额外施压一层，更快破势。
  - 赤霆 · 雷链：每个被斩中的敌人向附近最多 2 个敌人放出雷链（40% 伤害），每次交叉斩最多 4 道。
  - 霜轮 · 霜蚀：主手为霜轮时，每次双刀命中叠一层霜，第三层冻结目标（重度减速与冻伤）。
  - 空弦 · 虚刃：交叉斩额外射出 7 格剑气，打到第一排身后的敌人（50% 伤害）。
- **满蓄力强化**：赤霆满蓄力突击击杀敌人时“雷返”，冷却从 14 tick 降到 4 tick，可连续追击；霜轮满蓄力后半秒再“回霜”一圈（60% 伤害）；空弦满蓄力剑气给命中者打上“虚印”（发光 5 秒），之后你的双刀命中会引爆它（×1.25 伤害并加剑意）。
- **远程架刀**：交叉架刀也能挡正面飞来的投射物。精准窗口内完全抵消（箭矢仍会弹回），之后持续格挡减伤到 35%。
- **连斩计数**：HUD 右侧显示连续命中数。
- 以上均可在服务端配置中调整或通过 `bladeArts=false` 整体关闭，见 [配置说明](docs/CONFIGURATION.md)。

## 0.5.0 手持与动作

- 第三人称手持改为刀身从拳中笔直向前伸出、与前臂垂直、刃口朝下，正面、侧面、背面一致；修复了副手脇差被重复镜像而横穿身前的问题。
- 第一人称刀柄在右下，刀身向前上方延伸并露出刀面；蓄力居合时刀鞘沿腰带横向背后，手扶刀柄。
- 刀光、技能特效与奥义光效不再被错误地染成红色（0.3 起的着色缺陷）。

## 斩木与斩物

瞄准树干后下蹲蓄力出刀，会沿相连原木向上查找。默认短蓄力斩少量木头，满蓄力最多32格，每tick最多4格；不会自动伐叶或无限扩散到森林。其他方块按命中面的有限切面处理，蓄力越高，数量与硬度上限越高。

默认硬度上限5，跳过箱子等方块实体、不可破坏方块、流体、未加载区块和世界边界外目标。每一格都走原版玩家破坏与Fabric破坏事件，保护插件拒绝时停止本次斩物，冒险模式仍受限制。创造模式只在这次显式斩物流程允许刀破坏方块。

生存原木会按原版掉落。石头、矿物仍遵守原版“正确工具”掉落规则；刀不会变成镐。战斗蓄力不会自动破坏地形。除技能耐久外，斩物也会产生原版逐方块采掘耐久消耗；每次破坏前重新检查刀是否仍有效，刀碎立即停止。只有1点耐久时，满蓄力先支付原有8点技能消耗，因此会在破坏任何方块前碎掉。

## 配置

`config/oborokage-server.properties`：修改后运行原版 `/reload`。
`config/oborokage-client.properties`：修改后重新启动客户端。
完整字段和边界见 [配置说明](docs/CONFIGURATION.md) 及 `config-examples/`。

默认模组技能不伤玩家，并保护自己的宠物、盟友、村民和铁傀儡；服务器可分别调整。0.6.0 起单持刀的左键也走连斩，这些保护同样适用：持刀时左键不会伤到村民、铁傀儡与宠物（需要时可在服务端关闭对应保护，或换手再打）。`protectOthersPets=false` 默认保留对别人宠物的现有行为；设为 `true` 可同时保护其他主人拥有的宠物，修改后 `/reload`。对敌人的原胧影强度保留。
第三方特殊不死实体可加入实体类型标签 `oborokage:finisher_exempt`，该标签默认空：免除强制终结，仍承受普通伤害。非豁免目标会经过原有死亡流程及一次有界重试，仍存活则限频记录日志；第三方代码若主动阻止死亡或重写生命值，无法承诺通用兼容。

支持原版武器附魔。新招式调用实际所用刀的伤害、击后效果与击退；横扫之刃在交叉斩、范围招式上给予额外伤害。原刀的终结强度独立保留。

## 成就

原十项剑录保留。另有“一息，林木应声”（一次斩16原木）、“霜轮止戈”（一次减速3敌人）、“隔岸一线”（剑气命中16格外敌人）、“五刃同途”（同时携带五刀），0.4.0 的“残影见切”“雷鸣三响”，以及 0.5.0 新增的“奥义皆传”（施展全部五把刀的奥义）和“惊神泣鬼”（以奥义斩杀生命值不低于 150 的强敌）。聊天公告默认关闭，可在服务端开启；个人提示与进度页仍可见。

## 安装与回退

按上表把**一个**对应版本的 JAR 放进 `mods/`，移出旧版同 Mod ID 的 JAR。多人游戏（包括和朋友联机）中所有客户端与服务器需使用同一个 0.6.2 版本。从 0.3.x / 0.4.x / 0.5.x 升级不需要改配置；物品 ID 与存档数据格式不变。

**升级后有新增刀的世界不能直接降回0.1.0。** 实测旧版加载并保存后，脇差和新刀会消失，重新升级也不恢复。需要回退时，应同时恢复升级前的模组、配置和世界备份。0.5.0 起的各版本都没有新增物品或方块，战斗状态不写入存档；换回 0.5.0 的 JAR 即可回退（未实测）。
