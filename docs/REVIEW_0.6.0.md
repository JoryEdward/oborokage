# 0.6.0 设计与审查记录

## 反馈对照

| 反馈 | 做法 |
|---|---|
| 1. 奥义（除胧月一闪）名字显示太短 | `Cinematics` 的标题卡与运镜分离：施展后第 4 tick 开始书写，整段奥义期间保持，关键一击（原标题出现的节拍）放大提亮并补一笔，运镜结束后再停留 60 tick、最后 24 tick 淡出。被中途取消的奥义会清掉标题；奥义正常结束后紧接着出刀不会抹掉它。 |
| 2. 单持一把刀左键没有特效与伤害加成 | 新增单刀三段连斩 `SOLO_1/2/3`（16 / 18 / 28 × 刀威力），走与双刀相同的服务端判定、预测与剑意；末段五种终式；双手持握动作与第一人称动作；对应的提示文本。 |
| 3. 普攻与蓄力特效单一简陋，第三人称只是两条光弧 | 刀光重写为 `SlashFx`（每把刀各自的刃线、光幕、残影与装饰，末段放大并有地面光环，命中闪光，顿帧与镜头轻震）；蓄力四段 `ChargeFx`；本刀技 `TechniqueFx` 重写。 |
| 4. 其余奥义伤害上调；胧月一闪全新效果但不脱离施展方式 | 四个 J 奥义与双月归寂上调约 25–35%；胧月一闪保持“蓄力—松开—突进拔刀”，把“一刀杀多敌”和“静中收刀”做成核心：突进中只标记，入鞘时同时斩落；全新运镜与世界光效。 |

## 单刀连斩

| 段 | 时长 / 命中 tick | 基础伤害 | 角度 / 距离 | 动作 |
|---|---|---:|---|---|
| 1 袈裟斩 | 10 / 3 | 16 | 120° / 3.9 | 双手举刀于右肩上方，斜劈到左下 |
| 2 逆袈裟 | 10 / 3 | 18 | 130° / 3.9 | 自左下斜撩到右上，斜度较平 |
| 3 踏步横斩 | 16 / 6 | 28 | 160° / 4.4（胧月 360°） | 第 3–5 tick 向前踏 0.9 格，横扫，带横扫附魔加成与轻微击退 |

- 条件：主手是五把刀之一、副手不是脇差。副手拿脇差时仍是原双刀连招。连段在两者之间切换时从对应的第一段开始（`Move.follow`）。
- 伤害与双刀相同走 `WeaponDamage`（力量、虚弱、附魔、横扫），遵守 `TargetRules` 与每段目标上限；命中的剑意、施压破势、霜轮叠霜与双刀一致。
- 原版普攻对生物被拦下（`AttackEntityCallback`）。末影水晶、展示框、船等非生物仍是原版攻击；瞄准方块且附近没有敌人时左键照常挖掘，下蹲始终挖掘。村民、铁傀儡、宠物与其他玩家默认受保护，持刀左键不会伤到它们。
- 单刀伤害（以胧影为例，不含暴击）：一轮 62 / 36 tick，约每秒 34；原版满冷却普攻约每秒 18。双刀一轮仍更高（胧影 + 脇差约 96 / 35 tick）。

## 刀光（SlashFx）

- 每一刀的平面由“翻滚角 + 起止角 + 半径 + 高度”描述，左手的刀在镜像坐标中复用同一定义（交叉斩的第二刀就是第一刀的镜像）。
- 审查中发现：斩面包含视线方向时，从肩后看只是一条细线——这正是“两条光弧”的原因。现在把斩面的远端抬起 22°（回旋斩 12°），刀面朝向常用镜头；第一人称改为画在视野前方 1.8 格、面向镜头的新月。
- 层次：刀面光幕（靠刀柄透明、刃下最亮、尾部渐隐）→ 残影（胧影两道、其余一道、胧月无）→ 刃线（刀平面内的带 + 面向眼睛的带，侧看也不会消失）→ 白色刃芯 → 刃尖十字闪光 → 末段地面光环。
- 各刀：胧影刃线最宽；胧月最细、更快（时长 ×0.75）、刃尖洒花瓣；赤霆刃线是每 tick 重新生成的锯齿雷电并分出支电；霜轮每 14° 留一根冰棱，冰棱随刃长出、消退较慢；空弦细弦外有暗色光晕，整条弦停留并颤动后消散。
- 渲染：与 0.5.0 相同，`trailShaderCompat=true`（默认）走发光实体半透明层且单面，`false` 走信标光束层并双面；所有效果都按 `trailVertexBudget`、`trailDistance`、`trailMaxPlayers` 限制。新增：任一顶点离镜头不足 2.2 格（第一人称 0.9 格）时淡出。

## 蓄力（ChargeFx）

四段阈值为满蓄力的 25 / 50 / 75 / 100%。服务端原有的起手、半程、满蓄力音效保留，25% 与 75% 由客户端补一声。光阵画在脚下；第一人称下不画会正对镜头的光柱，环绕光点保持在视线以下。

## 胧月一闪

| tick | 服务端 | 画面 |
|---|---|---|
| 0–11 | 原地蓄势（不变） | 巨月自身后升起，脚下水纹，光点向刀柄汇聚；低机位正面推近 |
| 12–17 | 每 tick 2.5 格突进（原 2.0），斩击判定宽 2.2 格（原 1.65）；途经敌人记入标记、清零位移 | 光痕、风压线、残像；镜头甩到侧面跟拍 |
| 18–33 | 每 tick 把标记的敌人按在原地（水平速度清零、停止寻路） | 镜头绕到正面，你静立、身后敌人定格；画面沉寂，月面与每个敌人身上的刀痕随收刀逐渐发亮；28–31 振刀，31–34 收刀 |
| 33 | 收刀轻响 | |
| 34 | 入鞘：所有标记的敌人同一 tick 内 `strikeTarget`（1000 输入 + 原有终结），计入“月下无痕”击杀 | 白闪、屏幕横切、月亮沿刀痕裂开、光痕爆散、每个敌人处炸开刀痕与花瓣 |
| 42 | 居合结束（原 38） | 镜头拉远，花瓣沿斩线飘落，到 64 tick 结束 |

- 非满蓄力的居合仍是即时命中，不受影响。
- 安全性：玩家在入鞘前死亡、下线、换维度或上马，居合被移除，标记的敌人不会被斩（它们只是短暂停住）。入鞘时只处理仍存活、同维度、48 格内且仍符合 `TargetRules` 的目标。一次最多标记 64 个，超出的在接触时直接斩。
- 突进中的敌人不再在接触时受伤，因此不会在定格期间反击或被击退；如果它们在 34 tick 前已被别的伤害杀死，入鞘时跳过。
