# 审查建议落实

| 审查项目 | 0.3.0修改 | 证据/边界 |
|---|---|---|
| 本人动作等待网络往返 | 双刀本地Scene预测、序号ack/reject、缓冲、时钟微调 | 实际本机及200ms注入联机检查；伤害不预测 |
| 4tick格挡高延迟困难 | 单程延迟换算并封顶额外3tick | 受控RTT200/5000ms边界测试；不宣称回滚伤害 |
| 点按架刀刷剑意 | 起手消耗、重启/空架冷却、回架势延迟、同来源奖励节流 | 服务器拒绝重启及同源箭奖励测试 |
| 原居合误杀宠物/盟友/村民/傀儡 | 与新刀共用TargetRules，独立配置 | 拥有实体、队伍与配置开关测试；敌人强度保留 |
| 光影下刀光 | 原生自发光透明层和回退开关 | 实际Complementary+Iris+Sodium截图；其他光影未知 |
| 不死实体边界 | 空的豁免标签、标准死亡有界重试、限频日志 | 数据包注入豁免测试；主动复活第三方代码未穷举 |
| 无敌帧仍扣架势 | 减伤移到actuallyHurt调用参数 | 真实连续hurtServer第二击被忽略且架势不变 |
| 闲置状态包 | 仅装备/变化时同步 | 源码与生命周期网络检查；没有每5tick闲置广播 |
| 成就每tick根查询 | 20tick根检查，成就逻辑仍服务器权威 | 原成就回归与新增成就客户端检查 |
| Move及刀鞘逐帧分配 | 静态Move、未知ID安全空动作、栈/渲染状态有界缓存 | 加载、场景、资源与缓存代码检查 |
| 药水/攻击属性不生效 | 以实际属性与所用刀基准缩放 | 力量、虚弱、额外修饰、实际伤害测试 |
| 击后附魔遗漏 | 正确武器DamageSource及原生post-attack调用 | 锋利、亡灵杀手、火焰附加、击退、节肢杀手、横扫测试 |
| 新影步/奥义反复teleport | 新动作使用受碰撞约束的速度同步 | 真实客户端影步、墙与联机；原居合移动保留 |
| 损坏配置崩溃 | 严格解析、夹取、默认值、警告 | 非法布尔/NaN/损坏Unicode测试 |
| 奥义定位重复 | 更大范围/三次窗口/提前破势与减速，终结强度保留 | 服务器及两客户端奥义击杀和镜头恢复 |
| 架刀不挡箭 | 实体碰撞前弹回，归属变更，友方保护 | 受控与真实箭碰撞；低FPS测试先稳定玩家位置 |
| 数值写死 | 剑意/架势/格挡/影步/破势/奥义/斩物参数服务端配置 | `/reload`原生路径验证；旧刀强度不受新伤害倍率影响 |
| 键位和新手体验 | 重绑定、首次提示、实际冲突名称；HUD位置/缩放 | 真实客户端提示/布局截图 |
| 构建版本/依赖 | Loom1.18.4、API>=0.162.0、~26.3及Java25 | 构建与正式实例核对；不承诺26.4 |
| 一行压缩代码 | 固定格式器及formatJavaCheck | 所有生产/QA Java格式化 |
| QA计数器/作者包 | 观察计数移至QA JAR，独立oborokage包与贡献者归属 | 发布JAR结构审查 |
| 成就刷屏 | 本模组公告服务端开关，默认关闭 | 仅拦本模组，保留个人toast |
| 路径绑死/文档混杂 | 环境变量参数、用户/开发/配置/验证分文档 | 本机运行；其他OS需提供实际环境 |
| 0.1回退后果 | 独立真实保存/降级/重开/升级 | 新增刀变AIR且重升不恢复；原刀保留 |
| 测试可维护性 | 受控回归、真实客户端、两客户端、原生GameTest两项 | 真人手感与长时大规模压力仍未验收 |
| 更多刀和定位 | 三把主刀+脇差通用组合，快攻/控制/远攻/终结分工 | 五刀创造栏、配方、模型和技能检查 |
| 随能量斩物/伐木 | 显式下蹲蓄力、有限原木遍历、原生破坏/掉落 | 生存32原木守恒、权限/冒险/创造、箱子基岩保护 |

“验证过”仅指VERIFICATION列出的实际环境与测试；视觉最终喜好、长时间多人负载和任意第三方不死逻辑没有被这些测试替代。
