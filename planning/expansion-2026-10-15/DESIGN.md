# 胧影：单刀居合与双刀流扩展设计

状态：2026-10-15 的设计提案，尚未实现。用户要求暂停水桶弓更新，后续重点扩展太刀。本文不改变现有游戏行为。

## 现状已核对

工程：`OborokageTachi/`；Mod ID `oborokage`；旧物品 `oborokage:tachi`；已安装 0.1.0。
目标仍为本机 Minecraft 26.3 / Fabric Loader 0.19.5 / Fabric API 0.162.0+26.3 / Java 25。

代码已有：普通左键近战、40 tick 蓄满、右键松开居合、最多约 12 格碰撞突进、满蓄力 1000 输入伤害及存活目标终结、第三人称奥义「胧月一闪」、无伤三杀成就「刀已归鞘，月仍未落」。已有玩家伤害默认关闭和客户端镜头/震动开关。

没有：真正的副手独立攻击、连段状态机、精准格挡、架势值、剑意资源、闪避派生、武器专精、不同流派奥义。
旧 VERIFICATION.md 记录服务端 20 条和整合包客户端 12 条通过；本轮仅阅读代码、核对发布 JAR 哈希，没有重跑游戏，也没有确认所有旧视觉问题已解决。

## 推荐玩法骨架

以“观察攻击 → 闪避或格挡 → 交替出刀积累剑意 → 破势 → 奥义收刀”形成循环。先做单刀和双刀两种明确的战斗风格，再增加招式。继续采用银白刀光、淡紫余辉、黑漆刀鞘的审美，强度通过动作和刀路体现。

### 武器与流派

- 单刀：保留胧影太刀，长距离、节奏较慢、精准居合。保留原物品 ID 和原有奥义。
- 双刀：第一阶段只增加一把「胧月脇差」（暂定 `oborokage:wakizashi`）。主手胧影太刀、副手脇差时进入双刀流；主刀负责长弧与突进，副刀负责近身快斩与交叉防御。
- 两把武器分别占用真实物品槽，分别有耐久、附魔和掉落。禁止额外生成一把仅有外观却被当成真实装备结算的刀。
- 两把长太刀同时装备、任意剑混搭、反向主副手组合暂不自动视为支持。先做好一种长短搭配；左撇子玩家仍必须完整支持。
- 不以新增十把换色武器作为首期内容。新玩法应来自招式之间的选择。

### 建议操作

所有新按键可重绑定；以下是建议初值，接手者先检查本机按键冲突。

| 操作 | 单刀 | 双刀 |
|---|---|---|
| 左键攻击 | 单刀三段：袈裟斩 → 反袈裟 → 前突横斩 | 主手斜斩 → 副手反切 → 双刃交叉斩 |
| 右键按住/松开 | 保留原蓄力居合 | 继续保留主手太刀原蓄力居合 |
| 架刀键（建议 G） | 首期不强行增加功能 | 交叉架刀；受击时按格挡规则结算 |
| 精准格挡后再次左键 | 可后续加入弹反派生 | 短时间内触发「错月反切」 |
| 闪避键（建议 V）+移动方向 | 短步侧移，结束可接居合 | 短步绕身，结束可接副手快斩 |
| 奥义键（建议 R） | 原版居合不受此键限制；可映射现有奥义 | 满剑意施放双刀奥义 |

只接管持有指定武器且满足战斗状态的输入。空挥、挖掘、使用门箱、吃喝、副手火把等交互必须有明确定义；不要全局吞掉鼠标或原版换手键。单刀旧右键操作继续可用。

### 首批招式与反馈

1. **交替三连**：左右手各有出刀、命中、收势时刻。末段交叉斩产生两条真正交叉的世界空间刀路。连续点击只缓冲下一招，不把整套动作瞬间播完。
2. **错月反切**：架刀最初建议 4 tick 为精准格挡窗，仅处理来自前方、在允许类型内的攻击。成功闪出小型十字火花与短促金属声；在建议 12 tick 内左键反击。持续举刀只减伤并消耗架势，不能无限无敌。
3. **影步**：建议 2–3 格短步和约 16 tick 冷却；首版无全程无敌。撞墙停止，不穿实体保护区、不跳过坠落结算，不自动追踪绕到目标背后。
4. **剑意**：命中、精准防御、完成有效交替连段积累，受到有效伤害或长时间脱战后衰减。相同攻击刷同一目标有收益递减；不靠攻击无敌目标、队友或零伤害事件刷满。
5. **破势**：先只作为本模组记录的短时状态；玩家/普通怪/Boss 分别配置阈值与效果。普通怪可以短暂硬直，Boss 默认只开放反击伤害窗口，不能笼统清空 Boss AI 或锁死行动。
6. **流派专精（后续）**：通过完成特定战斗行为解锁派生选择，例如更快反切或更远影步；优先横向选择，不做无限叠伤数值树。不额外依赖材料堆叠才能体验双刀。

### 双刀奥义「双月·归寂」

推荐演出约 2.4 秒，具体帧数要实机调整：

- 0–0.35 秒：两刀交叉压低身体，短促近景；一银一淡紫的刃光沿刀身亮起。
- 0.35–0.8 秒：碰撞约束下短距离前突，主手横切、副手反切形成 X 型月弧；双方攻击各有独立命中时刻。
- 0.8–1.5 秒：角色完成反向转体交叉终斩，留下两条延迟消散的残影。终斩沿服务器认可的实际路线，不隔墙自动击杀。
- 1.5–2.4 秒：镜头稍拉远，刀光断开、粒子沉降，两刀依次收势；终斩结算必须对应可见刀路，不在字幕出现时提前杀死目标。

奥义镜头属于施术者客户端。其他玩家看到角色动作和刀光，不被强制切镜头。允许关闭自动镜头、震动、黑边；手动切视角、死亡、换维度或打开界面要可靠退出。不开电影镜头也必须看懂攻击。

首期不实现真实全局慢动作/暂停世界；可用本地动作曲线、短促视觉停顿与音效制造顿挫，服务器时间照常推进。

## 硬性要求：原版太刀不得削弱

用户已明确要求保留原始版本强度。这是实现约束，不是可自行调整的平衡建议。

- 保留 `oborokage:tachi`，保持旧物品与存档可读。
- 40 tick 满蓄力、最低 4 tick 有效释放。
- 保留伤害公式 `15 + 985 × q²`；满蓄力输入伤害 1000，存活目标继续进入现有终结处理。
- 保留满蓄力前摇 12 tick、6 tick 突进、每 tick `0.9 + 1.1 × q` 格的请求移动量；满蓄力无障碍最大约 12 格。
- 保留部分/满蓄力冷却 18/45 tick、耐久消耗 2/8、总耐久 4096，以及现有基础近战注册属性。
- 不增加剑意、体力、材料、击杀数、等级、连段、破势或技能解锁门槛；原版右键居合随时按原规则使用。
- 不因重构额外增加启动等待、强制后摇、缩小命中范围或取消原来的护甲/抗性处理。保留正常墙体、使用者与玩家保护。
- 不加入会弱化旧刀的“技巧模式”或自动平衡预设。先前的双预设建议已撤回。
- 持有双刀时也不能让原版太刀丢失居合：新增独立可重绑定的架刀键（建议 G）用于双刀格挡，右键继续触发太刀原版居合。双刀奥义另用 R；不得共享冷却把旧居合锁住。

新增玩法的价值来自左右手动作、应对方式、位移和奥义演出。承认旧刀本来就能终结大多数目标，不为了迫使玩家使用连招而削弱它。剑意只增强新增双刀招式/双刀奥义；普通连招不滥用强制终结接口，新增双刀奥义可以保留同等级终结能力，但明确每个结算窗口，避免重复死亡回调。

## 成就提案

保留原成就 ID 与条件。新增优先选两个：

- **双月同辉**：一次双刀连段中，主副手各有效命中，最后交叉斩击败目标。记录具体动作 ID、手别和目标，不能仅按一次事件的伤害次数判断。
- **借你一刀，还你一月**：成功精准格挡后，在反击窗口内用「错月反切」击败本次攻击来源；不得用另一个无关目标刷取。
- 后续隐藏挑战 **三息不乱**：一次战斗对三次不同攻击完成精准防御，期间没有实际受伤；需要排除多段同源伤害刷计数。

奖励先用称号/成就和外观细节，不再追加装备。成就由服务器授予；任何皮肤装饰不得改变碰撞判定。

## 阶段与验收

1. 拆分状态机和网络时序；旧单刀行为回归通过，再加新招。
2. 一长一短的双刀静态握持、两侧刀鞘、主副手切换；检查第一/第三人称、左右利手、蹲伏/奔跑/跳跃，关闭特效也看清刀路。
3. 主副手交替三连：正确武器扣耐久，窗口去重，无双重原版攻击，无空挥刷资源。
4. 精准格挡、反击及仅用于新玩法的剑意；加入两项成就。
5. 完整双刀奥义及第三人称镜头；实机逐阶段截图与真实攻击记录对应。
6. 影步和破势深化；多人延迟与兼容验证。
7. 专精、空中派生等后续内容。首期不做自动追踪多目标瞬移、世界时停或巨型新技能树。

每阶段可交付独立可用版本。最终使用临时世界验证；安装前备份旧太刀 JAR/配置/源码，保留用户世界、水桶弓和其他模组。水桶弓冻结在当前版本。
